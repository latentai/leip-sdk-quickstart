# Tutorials

!!! note "Download Individual Notebooks"
    Download tutorials individually using the link in the upper right-hand corner of each notebook. Then, move each notebook into the mounted Docker volume (the local directory you've shared with the container using the `-v` or `--volume` flag) to access it from within the container.

[**Optimize for TensorRT**](BYOMwithForgeTutorialOnnx.ipynb): Step-by-step instructions for using LEIP Optimize to optimize for a target with TensorRT support.

[**Optimize for Android**](BYOMwithForgeAndroidTutorial.ipynb): Step-by-step instructions for optimizing a model for an Android target.

[**Optimize a Quantized Model for Android**](BYOMwithForgeAndroidQTutorial.ipynb): Step-by-step instructions for optimizing a quantized model for an Android target.

[**Optimize for CPU**](BYOMwithForgeTutorialTVM.ipynb): Step-by-step instructions for using LEIP Optimize to optimize for a CPU target.

[**Encrypt a Model**](EncryptionwithForgeTutorial.ipynb): Step-by-step instructions for encrypting your optimized artifact.
